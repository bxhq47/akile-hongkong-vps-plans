## 线路：移动用户占便宜，电信联通走的是普通骨干

Akile 香港的路由是这样分配的：移动双向 CMI 直连，电信去程绕 AS10099、回程走 163，联通双向 AS10099。翻译成体感：移动宽带的用户访问延迟和稳定性最好，电信回程落到 163 骨干，晚高峰能不能跑满取决于当时 163 的拥塞程度，联通介于两者之间。

## 常见问题

**500GB 流量对个人站够不够？** 日均几千 PV 的静态站或轻博客，一个月通常跑不到 100GB。带图片的 WordPress、有文件下载的站，500GB 可能两三周就见底。

**流量超了会停机吗？** 不会。限速到 10Mbps，机器继续运行，下个计费周期流量清零恢复原速。

**能升级配置吗？** 套餐是固定配置，我没有核验到官方的在线升降配入口。香港这条线上，加钱换来的主要是流量和带宽，硬件规格的档位不多，选之前把配置定准比事后折腾划算。

**7 天退款好申请吗？** 政策和条件都在，但流量阈值的具体数字官方没公开，稳妥做法是拿到机器当天就测线路，48 小时内决定去留。

**数据中心 IP 和住宅 IP 差别在哪？** 数据中心 IP 属于机房段，流媒体平台和电商风控普遍有黑名单，识别率高；住宅 IP 属于普通宽带用户段，被当作家庭用户放行。Akile 香港是前者，做流媒体账号验证类业务要选后者。

**支持哪些付款方式？** 支付宝、微信、PayPal。美元标价的套餐按结算时汇率折算。
